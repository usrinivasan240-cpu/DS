# Data Structures Practical Programs (C++)

Complete question-wise collection for all 60 questions in `ds_practical_important_question.pdf`.

## Compile and run

Compile **one source file at a time**, because every program has its own `main()`.

```bash
g++ -std=c++17 -Wall -Wextra -pedantic 01_stack_using_array.cpp -o program
./program
```

## Source-specific notes

- Q9: The question refers to a weighted graph image, but the extracted PDF text does not include its edge weights. The program accepts an adjacency matrix and uses A as the source.
- Q12: The question does not provide a particular sorted array or search key; the program accepts both as input.
- Q18: The question gives the graph but does not specify a starting vertex. The existing implementation uses vertex 0 and labels that assumption.
- Q29: The question refers to a graph image with vertices A-G; its weights are not present in the extracted text. The program accepts a 7x7 weighted adjacency matrix and starts at A.
- Q33, Q38, Q40, Q41, Q42, Q44, Q48, Q52, Q53, Q58, Q59 and Q60 accept user input where the question does not provide fixed sample data.
- Q52 requires the names to be entered in alphabetical order, as required by binary search.
- Priority queue examples use a larger numeric value to mean higher priority.
- Infix-to-postfix examples use single-character operands; unary operators and multi-character identifiers require token-based parsing.
- Q39 bucket sort assumes values in the range [0, 1), as specified by the question.
- Q59 uses vertex numbers 0 through n-1.
- Always test programs with your instructor's expected inputs and conventions.
