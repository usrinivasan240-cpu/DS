# Practical preparation notes

1. Compile each question independently using C++17.
2. Practise dry runs for stack, queue, list, tree, heap and graph operations.
3. Check edge cases: empty structures, full arrays, absent keys, duplicate keys, disconnected graphs and invalid positions.
4. Understand the algorithm and its time complexity; do not rely only on memorising source code.
5. See README.md for question mapping and source-question omissions.
